### 🧠 AI Assistant / Agent Architecture — *flagship project*

Designing a skill-based agent architecture that separates reasoning from execution:

| Component | What it does |
|---|---|
| **Skill system** | `skills/` directory of structured `SKILL.md` definitions — creation, validation, routing, dependencies |
| **Planner** | Reasons over execution steps, emits structured tool calls (`read`, `write`, `exec`) with explicit arguments |
| **External runner** | Executes the LLM's structured tool-invocation output, keeping reasoning and execution cleanly separated |

This is the core of my current direction: reliable agent infrastructure, not just prompt-and-response.
